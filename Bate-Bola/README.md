## Descrição

O BateBola é uma aplicação desenvolvida para facilitar a criação,
organização e participação em partidas esportivas informais.

## Tecnologias utilizadas

- Python
- Flask
- SQLAlchemy
- SQLite/MySQL
- HTML
- CSS
- JavaScript
